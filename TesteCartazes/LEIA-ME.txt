TesteCartazes - teste do poster SEM MySQL e SEM mexer no seu projeto
====================================================================

Este e um projeto separado. Os dados ficam na memoria (somem ao fechar).

COMO ABRIR NO ECLIPSE
  1. File > Import > General > Existing Projects into Workspace
  2. Escolha a pasta TesteCartazes (ou o .zip) e clique em Finish
  3. Botao direito em src/main/Main.java > Run As > Java Application

O QUE TESTAR
  - Escolher poster: abre o seletor (so jpg, jpeg, png)
  - Cadastrar sem poster: funciona, a moldura mostra "Sem poster"
  - Cadastrar com poster, depois clicar no filme da lista: o poster aparece
  - Clicar num filme sem poster: mostra "Sem poster", sem erro
  - Limpar: limpa os campos e o poster
  - Data no formato dd/mm/aaaa (ex.: 25/12/2026); 31/02/2026 e recusada
  - Indicacao e um NUMERO: 0 (livre), 10, 12, 14, 16 ou 18
  - Cadastrar duas vezes a mesma data: mostra "Data ja cadastrada."

TESTE DE CONSOLE (sem janela)
  Run As > Java Application em src/main/TesteFoto.java

DIFERENCA PARA O PROJETO REAL
  Apenas o model/EstudanteBD.java: aqui e a versao em memoria
  (as regras, em model/Regras.java, sao as mesmas das do projeto real).
  No projeto real, use o EstudanteBD.java com MySQL.
  Todos os outros arquivos sao identicos aos do projeto real.
